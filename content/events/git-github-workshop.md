Bring a machine with Git installed. We will provide a starter repository and a small project to work on, so you can follow along without setting up anything complicated.

## What to expect

- short explanations followed by hands-on work,
- branching, merging, remotes, and pull requests from the first hour,
- a deliberately created merge conflict to solve together,
- no long slide deck; most of the session happens inside a terminal and GitHub.

If you already use Git, come anyway: the conflict challenge gets progressively messier.
