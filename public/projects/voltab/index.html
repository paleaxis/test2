PROJ.04 — Electronics / 2024

VoltLab

An ESP32 datalogger the physics department actually uses in first-year labs.

Status complete
Stack
ESP32 C MicroPython React
Links
GitHub ↗

01 — Context

Why this exists.

VoltLab replaces the paper stopwatch-and-ruler approach to capacitor discharge experiments with a $6 board that plots curves to a browser dashboard in real time.

DIAGRAM // PROJ.04

02 — Problem

The situation we started from.

Problem statement

Physics practicals measure capacitor discharge by eye and by hand. The results are noisy, slow, and demotivating. The department wanted data, not sketches.

03 — Approach

How we went at it.

01 DAQ

ESP32 samples the ADC at 1 kHz, applies a moving average, and streams frames over WebSocket.

02 Fit

The dashboard fits an exponential decay in the browser and reports tau with residual error, so students check theory against measurement.

03 Zero config

The board creates its own access point; students connect and open one URL. No drivers, no install.

05 — Result

What actually happened.

Result

Adopted for the 2024–25 first-year lab batch. Time constant measurements now agree with the expected value within 5%.

FIELD NOTE — A physics teacher now co-advises the electronics reading group.
