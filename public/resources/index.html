00 — Resources

A CURATED KNOWLEDGE BASE, NOT A LINK FARM.

These are the books, manuals, tutorials and tools the club actually uses and recommends — every one checked by a study group before it lands here.

01 — Knowledge base

The shelf.

book

The C Programming Language

The book that teaches C and, by extension, how a computer actually executes code. Read it twice — once for syntax, once for the model it gives you.

Programming · Beginner ↗
book

Structure and Interpretation of Computer Programs

The classic text on building abstraction layers. Demanding, and worth every hour. The full text is free online.

Programming · Intermediate ↗
tutorial

Composing Programs

A modern, web-native adaptation of SICP with Python. The club's entry point for first-years who want the SICP mindset without the Scheme.

Programming · Beginner ↗
tutorial

The Missing Semester of Your CS Education

MIT's crash course in the tools every student is assumed to know but nobody teaches: shell, editors, git, debugging, data wrangling.

Dev Tools · Beginner ↗
documentation

git-for-beginners (official docs)

Start with the Pro Git book's first three chapters, then use the reference. Skip the ten-minute videos.

Dev Tools · Beginner ↗
repo

The Art of Command Line

A dense, single-file field guide to the command line. Read one page a day and try everything it mentions.

Dev Tools · Intermediate ↗
tutorial

Linux Journey

A structured path through Linux basics: the filesystem, users, permissions, processes, and networking, with practice pages.

Linux · Beginner ↗
book

The Linux Command Line

A free, thorough book that turns you from a clicker into someone who composes commands. Our first-year recommended reading.

Linux · Beginner ↗
article

man pages you should know

Why `apropos` and `man -k` are your first debugging tools. Learning to read documentation beats memorizing it.

Linux · Intermediate ↗
book

Operating Systems: Three Easy Pieces

The canonical free OS text: virtualization, concurrency, persistence — with projects that mirror what our systems group builds.

Systems · Intermediate ↗
book

Computer Systems: A Programmer's Perspective

CS:APP connects C, assembly, the memory hierarchy, and links/loading into one coherent picture. The lab assignments are legendary.

Systems · Intermediate ↗
book

Systems Performance

How to measure systems before theorizing about them. Reaches for when you want to understand why things are slow, not just that they are.

Systems · Advanced ↗
documentation

MDN Web Docs

The only web reference we recommend. If a web answer isn't from MDN, verify it against MDN before trusting it.

Web · Beginner ↗
book

Web Browser Engineering

Build a tiny web browser from first principles in 400 pages. The best cure for 'magic black box' thinking about the web.

Web · Advanced ↗
article

CSS for Engineers

Layout as an engineering problem: box model, flow, flexbox, grid, and why 'make it work' comes before 'make it pretty'.

Web · Intermediate ↗
tutorial

Practical Deep Learning for Coders

fast.ai's top-down course: train real models in lesson one, then fill in theory. We run this inside our AI reading group.

AI / ML · Beginner ↗
book

Neural Networks and Deep Learning

Michael Nielsen's free, interactive book. The chapter on how backpropagation actually works is the best one we know.

AI / ML · Intermediate ↗
tutorial

Hugging Face NLP Course

From tokenizers to fine-tuning, hands-on. The companion to our Nodhini project.

AI / ML · Intermediate ↗
tutorial

PortSwigger Web Security Academy

Free labs that teach web vulnerabilities by making you exploit them. The best practical security training that exists for free.

Security · Intermediate ↗
tool

OverTheWire Bandit

A level-based game that teaches Linux security basics through puzzles. Our CTF team's warm-up.

Security · Beginner ↗
tool

CryptoPals

Cryptography challenges that force you to implement attacks, not memorize them. Expect to feel humbled.

Security · Intermediate ↗
book

The Algorithm Design Manual

Skiena's practical take on algorithm design — a catalog of problems and when to reach for them, instead of a wall of proofs.

Algorithms · Intermediate ↗
tool

CSES Problem Set

300 curated problems ranked by difficulty. Our algorithms group's homework source.

Algorithms · Intermediate ↗
tool

VisuAlgo

Interactive algorithm visualization. Pair it with our own AlgoPlay and you will never need a gif again.

Algorithms · Beginner ↗
book

The Art of Electronics

The engineer's handbook for circuits. Keep it next to VoltLab's bench; answer 'why is it doing that?' before touching the firmware.

Electronics · Advanced ↗
documentation

ESP32 Technical Reference

The datasheet-ish manual for our datalogger board. Learning to read reference manuals is a skill; start here.

Electronics · Intermediate ↗
book

Practical Electronics for Inventors

A gentler entry than Horowitz & Hill, with the same honesty about how components actually behave.

Electronics · Beginner ↗
tutorial

How to Contribute to Open Source

Open Source Guide's checklist for a first contribution, from reading CONTRIBUTING to surviving your first review.

Open Source · Beginner ↗
article

Choosing a License

What MIT, Apache-2.0, and GPL actually mean for your project. Read this before the club's next release.

Open Source · Beginner ↗
article

Semantic Versioning

The spec our projects follow. Version numbers are communication; learn to speak it.

Open Source · Beginner ↗
